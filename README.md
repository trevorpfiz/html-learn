# html-learn

Notes and experiments from learning to use the `html-plan` Claude Code plugin, which generates HTML plans with simple language, code snippets, surfaced questions and mockups.

## Setup

```sh
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install html-plan@claude-community
```

Restart Claude Code (or run `/reload-plugins`) after installing.

## Goal

Try the plugin on real tasks and collect feedback on the plans it produces.
